# Enterprise Edition install ZIP

Put the Oracle AI Database 26ai for Linux x86-64 ZIP here, for example
`LINUX.X64_2326000_db_home.zip`. Download it from
https://www.oracle.com/database/technologies/oracle-database-software-downloads.html
(an Oracle account is required). Do not unzip it.

Then run:

    ./local-26ai.sh build-ee-image

The ZIP is gitignored.
